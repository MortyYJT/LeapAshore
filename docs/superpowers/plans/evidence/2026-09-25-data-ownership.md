# OfferPilot Data Ownership Contract — 2026-09-25

This contract is for the parallel migration design. It does not migrate or copy production records. PostgreSQL remains canonical; derived copies are rebuilt from PostgreSQL and have an explicit deletion path.

## Ownership rules

1. PostgreSQL transactions define account, profile, consent, advisor thread, recommendation, task, feedback, and source-review truth.
2. MySQL is a read projection for new Agent-domain operations. It cannot decide source publication or modify PostgreSQL entities.
3. Milvus is a disposable search projection of published source versions. Its collection can be rebuilt from PostgreSQL and approved embedding configuration.
4. SQLite checkpoint is resumable graph state only. A checkpoint is never authoritative for account, profile, admission rule, or source facts.
5. Langfuse is operational telemetry. It is not the only audit record and must not be required to serve, delete, or recover a user account.
6. Memory/SQLite local development Stores preserve protocol behavior for tests but do not claim transactional outbox durability or production multi-instance safety.

## Deletion propagation

1. In the PostgreSQL account-delete transaction, delete canonical user data and enqueue tombstones carrying only stable opaque projection/thread refs and the event ID; never persist email, password, raw profile, or raw message in the tombstone.
2. The worker retries MySQL deletion and checkpoint deletion until acknowledged. Idempotency is the event ID plus projection name; repeat deletion is safe.
3. Delete Langfuse traces only through the protected trace-ID index. If this index is not retained, rely on explicit short retention and state that immediate per-user trace erasure cannot be guaranteed.
4. Retain immutable backups only for the approved retention period. Restores must apply deletion tombstones before exposing restored records to users.
5. A deletion request is complete only after live projections/checkpoints are confirmed purged; backup expiry is reported separately.

## Open operational values

Before production rollout, record the agreed retention duration, checkpoint encryption/backup implementation, MySQL conversation projection fields, Langfuse trace TTL, and maximum Milvus source-withdrawal propagation time. Do not invent these values in code or claim them as verified until measured.
