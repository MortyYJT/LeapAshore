## 1. 这一阶段做了什么、为什么

- 问题：到 M1 为止，档案已落库，但**选校组合**与**申请进度**仍只在浏览器里；`GET /api/programs`
  虽然能用，前端却还在读硬编码的 `web/lib/programs.ts`（设计 §1）。
- 分四批（设计 §7）：M2a 建 `roadmap_phases` + `material_templates` 并出 `GET /api/roadmap`；
  M2b 建 `roadmap_tasks` + `task_events` 与重算 upsert；M2c 建 `applications` 并让前端组合脱离
  localStorage；M2d 让视图改读服务端目录。
- **算法留在浏览器**（§3.1）：`web/lib/roadmap.ts` 的倒推算法不在 Python 里重写，算完把结果
  `PUT` 给服务器。代价是服务器无法独立重算（半夜批处理、agent 无浏览器推算做不到），已知并接受。
- **每行标 `origin`**（§3.2，本阶段核心）：`roadmap_tasks` / `applications` 都带 `origin`
  （`system` / `user` / `agent`），重算只替换 `system` 行。被否决的替代是「重算=删光重建」——那会
  冲掉申请人勾过的完成状态和 agent 之前加的任务。
- **重算是 upsert，不是删光重建**（§3.3）：行的身份是 `(client_id, material_key, program_id)`；
  程序维度的材料用**空字符串**而非 NULL，因为 Postgres 的 UNIQUE 不约束 NULL。
- **重算必须由「服务端读到的定义」驱动**（§3.8，M2b 硬约束）：前端读定义失败时渲染内置副本
  `DEFAULT_DEFINITION`，而它**故意不含签证阶段**；若拿它重算，签证系统行会被当成「不再适用」删掉，
  下次用真定义重建时恢复成 `pending`，完成状态丢失。因此客户端只在真读到定义时才写
  （`web/lib/roadmap-definition.ts:readRoadmapDefinition`、`web/lib/roadmap-sync.ts:toReplacePayload`），
  并**另外**提交 `applicableKeys`，让服务端区分「不再适用（删除）」与「这次没带上（不动）」
  （`api/app/services/roadmap_tasks.py:replace_system_tasks`、`_reject_a_contradiction`）。
- 定义入库并从服务端取（§3.4）：`api/app/seed_roadmap.py` 从 `web/lib/roadmap.ts` 逐条转写六阶段与
  31 条材料；**新增第 7 个阶段 `visa`「签证与行前」**（§3.5），它是新写的、不是转写，两条签证材料
  各引用 Genuine Student 官网页；合计 7 阶段 / 33 条材料。种子有快照 + 对账脚本
  `scripts/verify-roadmap-mirror.cjs`（值级比对 TS↔快照↔库，且比对 0 行会失败）。
- 项目名归属（§3.6）：接口 `name` 是中文、`nameEn` 是英文，而前端 `Program.name` 存英文。裁定是
  **接口不改、前端适配器做映射**（`web/lib/programs-source.ts:toProgramView`，`name ← nameEn`），
  并把 5 个字段的可空性按接口修正，`null` 渲染成「未知」而不是空串。
- `task_events` 从 M2 就开始写（§3.7）：用户的勾选/调整（`api/app/services/roadmap_tasks.py:update_task`）
  与组合替换（`api/app/services/applications.py:replace_applications`）都记一条。
- M2c 组合落库（`api/app/models/application.py`、`api/app/routers/applications.py`、
  `api/app/services/applications.py`）：整体替换；`UNIQUE (client_id, program_id)`；部分唯一索引
  `uq_applications_one_primary_per_client`（谓词 `WHERE is_primary`）保证每人至多一个首选。
- 前端 `web/lib/store.ts` 里的 `portfolio` / `completedMaterials` 退役为**渲染数据源**（字段仍在
  持久化契约里、`saveState` 仍会写，但没有任何渲染读回；`web/app/page.tsx` 的渲染状态来自
  `fetchApplications`）；`PortfolioPicker`、`HomeView`、`FlowView` 改读服务端

  的对照物与测试夹具，`scripts/check-no-programs-import.cjs` 用导入图阻止页面再读它。
- 关键文件：`api/app/models/roadmap.py`、`api/app/models/task.py`、`api/app/models/application.py`、
  `api/app/routers/roadmap.py`、`api/app/routers/applications.py`、
  `api/app/services/roadmap_tasks.py`、`api/app/services/writes.py`、`api/app/seed_roadmap.py`、
  `web/lib/roadmap-sync.ts`、`web/lib/roadmap-definition.ts`、`web/app/page.tsx`。
